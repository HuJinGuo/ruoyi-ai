# 一、核心实体与关联关系

### 1. 客户表 `crm_customer`

| 字段名         | 类型            | 说明                      |
| ----------- | ------------- | ----------------------- |
| customer_id | bigint        | 客户主键，唯一                 |
| name        | varchar       | 客户名称                    |
| short_name  | varchar       | 客户简称                    |
| code        | varchar       | 客户编码（企业内部唯一标识）          |
| type        | enum          | 客户类型（终端、集成商、代理商、供应商兼客户） |
| level       | enum          | 客户等级（A/B/C/D）           |
| industry    | varchar       | 行业分类                    |
| province    | varchar       | 省                       |
| city        | varchar       | 市                       |
| district    | varchar       | 区                       |
| address     | varchar       | 详细地址                    |
| website     | varchar       | 官网                      |
| status      | enum          | 潜在/合作/暂停/黑名单            |
| scale       | JSON          | 员工数、年营收、产线数量、工厂面积等      |
| created_by  | user_id       | 创建人                     |
| created_at  | timestamp     | 创建时间                    |
| updated_at  | timestamp     | 更新时间                    |

---

### 2. 联系人表 `crm_contact`

| 字段名           | 类型            | 说明                                |
| ------------- | ------------- | --------------------------------- |
| contact_id    | bigint        | 主键                                |
| customer_id   | bigint        | 所属客户（外键 crm_customer.customer_id） |
| name          | varchar       | 联系人姓名                             |
| phone         | varchar       | 手机                                |
| email         | varchar       | 邮箱                                |
| wechat        | varchar       | 微信                                |
| position      | varchar       | 职位（标准化）                           |
| department    | varchar       | 部门                                |
| decision_role | enum          | 决策/影响/使用/采购                       |
| created_by    | user_id       | 创建人                               |
| created_at    | timestamp     | 创建时间                              |
| updated_at    | timestamp     | 更新时间                              |

**关联关系**：
一个客户 `customer_id` 对应多个联系人 `contact_id`，一对多。

---

### 3. 商机表 `crm_opportunity`

| 字段名                  | 类型            | 说明                                  |
| -------------------- | ------------- | ----------------------------------- |
| opportunity_id       | bigint        | 主键                                  |
| customer_id          | bigint        | 客户                                  |
| contact_id           | bigint        | 负责人联系人                              |
| name                 | varchar       | 商机名称（项目名称）                          |
| estimated_amount     | decimal       | 预计金额                                |
| estimated_close_date | date          | 预计签单日期                              |
| source               | enum          | 项目来源（市场/客户推荐/其他）                    |
| stage                | enum          | 阶段（线索→需求沟通→方案设计→报价→商务谈判→待签约→已成交/失败） |
| success_rate         | decimal       | 成功率（自动根据阶段计算）                       |
| created_by           | user_id       | 创建人                                 |
| created_at           | timestamp     | 创建时间                                |
| updated_at           | timestamp     | 更新时间                                |

**关联关系**：

* `customer_id` → crm_customer
* `contact_id` → crm_contact
* 一个客户可以有多个商机，一对多。
* 商机会关联 **BOM / 报价 / 合同 / MES生产工单**，后续通过 `opportunity_id` 关联。

| ---------------- | ------------- | --------------- |

* `opportunity_id` → crm_opportunity

## 二、CRM 与其他系统的关联

| CRM模块 | 关联系统    | 关联字段                  | 说明            |
| ----- | ------- | --------------------- | ------------- |
| 商机    | PDM     | bom_id                | 商机确认后选择产品BOM  |
| 报价    | PDM     | bom_id                | 自动计算成本，生成报价   |
| 报价    | SRM     | purchase_plan_id      | 报价中包含采购计划建议   |
| 合同    | MES     | work_order_id         | 生成生产工单        |
| 合同    | WMS     | delivery_order_id     | 发货指令          |
| 合同/回款 | FINANCE | invoice_id/payment_id | 对应发票/回款       |
| 跟进记录  | SERVICE | service_ticket_id     | 跟进涉及售后问题可关联工单 |

## 三、设计原则总结

1. **外键命名清晰**：用 `xx_id`，避免通用 `id`。
2. **实体关系完整**：客户→联系人→商机→跟进→报价→合同→回款。
3. **领域边界清楚**：CRM 内部管理销售信息，PDM/WMS/MES/FINANCE/Service 用外键联动。
4. **可扩展性**：Tool/Agent 可以直接调用这些外键关联的数据。
5. **版本管理**：报价和合同支持版本。
6. **AI适用性**：跟进、报价生成、回款提醒、合同提醒都可接入 AI 工具。
